# 🩺 AI Health Education Assistant

An AI-powered health education application built with **Python and Streamlit**.

## Features

* 🩺 Symptom education
* 🛡️ Health and prevention tips
* 🚨 Emergency symptom detection
* 🤖 Gemini AI with Groq fallback
* 🎤 Voice input
* 📄 PDF export
* 📊 Analytics dashboard
* 🌙 Dark and light themes
* 🌐 Multiple language support

## Technologies

* Python
* Streamlit
* Google Gemini API
* Groq API
* Pandas
* SpeechRecognition
* FPDF

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

This application is for **educational purposes only**. It does not provide medical diagnosis or replace professional medical advice.
